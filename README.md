# SuperLUBase

> [!IMPORTANT]
> **This package is no longer maintained, and the repository is archived.**
>
> SuperLUBase.jl held common struct, function and constant definitions for the SuperLU
> libraries, frozen at the SuperLU_DIST 8.x layouts. Its only user was
> [SuperLUDIST.jl](https://github.com/JuliaSparse/SuperLUDIST.jl), which since v1.1.0
> generates all of these bindings itself with Clang.jl from the SuperLU_DIST 9.3.1 headers and
> no longer depends on SuperLUBase. Please use SuperLUDIST.jl.
>
> The registered versions of SuperLUBase remain installable.

Common struct, function, and constant definitions for SuperLU libraries.
